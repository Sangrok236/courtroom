# 법정의 모순 — AI 법정 게임 프로토타입

## 실행

Python 3.11 이상을 권장합니다.

```bash
cd courtroom_demo
uv run --with streamlit --with google-genai --with openai --with python-dotenv streamlit run app.py
```

또는 `pip install -r requirements.txt` 후 `streamlit run app.py`.

브라우저에서 표시된 로컬 주소로 접속합니다.

## 선택: AI 자유 대화 활성화

API 키 없이도 규칙 기반 대화와 증거 제시를 시험할 수 있습니다. Gemini 또는 OpenAI API를 연결하려면 `app.py`와 같은 폴더에 `.env` 파일을 만들고(`.env.example` 참고) `GEMINI_API_KEY=...` 또는 `OPENAI_API_KEY=...`를 적으세요. 둘 다 있으면 Gemini를 씁니다(`AI_PROVIDER=openai`로 바꿀 수 있습니다). 새 형식 키(`AQ.`로 시작)와 기존 `AIza` 키 모두 사용할 수 있습니다. 환경 변수로 직접 설정해도 됩니다. 모델은 `AI_MODEL`로 지정하며(공급자별 `GEMINI_MODEL`, `OPENAI_MODEL`도 가능) 비워 두면 `gemini-3.8-flash` / `gpt-4.1-mini`를 씁니다. 호출이 실패하면 화면에 오류 코드와 메시지가 표시됩니다. `.env`는 `.gitignore`에 포함되어 있습니다. API 이용 요금은 별도입니다.

## 사건 구조 (3층)

`cases/case01.py`에 사건이 세 층으로 정의되어 있습니다.

1. **진실** (`truth`): 실제로 있었던 일. 판정 AI만 압니다.
2. **증인이 아는 진실** (`witness.view`): 증인의 기억과 믿음. 증거로 반박되면 바뀝니다. 증인 AI는 이것만 압니다.
3. **증인의 목적** (`witness.goal`): `honest`(아는 대로 말함, 착각일 수 있음) / `frame`(누명을 씌움) / `protect`(누군가를 보호함). 목적에 따라 진실도 거짓도 말합니다.

`view`의 각 항목은 `{'text': ..., 'stance': ...}`이고 태도(`stance`)가 증인이 그 믿음을 말하는 방식을 정합니다.

| 태도 | 증인의 말하기 |
|---|---|
| 확신 | 단정적으로 말합니다. 증거로 틀렸음이 드러나면 인정하고 고칩니다 |
| 애매 | "~같습니다"처럼 흐려 말합니다. 파고들어도 확신으로 바꾸지 않고 지어내지 않습니다 |
| 숨김 | 질문만으로는 털어놓지 않고 부인하거나 둘러댑니다(거짓 가능). 증거로만 드러나며 목적보다 태도가 우선합니다 |
| 추측 | 직접 본 것처럼 말하지만 근거를 따지거나 증거로 지적받으면 추측이었다고 정정합니다 |
| 미언급 | 사실이지만 먼저 꺼내지 않습니다. 그 내용을 **직접 물으면** 사실대로 솔직하게 답하고, 넓은 질문에는 다른 사실로 답합니다(숨김과 달리 물으면 숨기지 않습니다) |

태도 키는 `engine.STANCES`와 `ai.STANCE_GUIDE` 두 곳에서 관리합니다.

증언에는 처음부터 참/거짓 값이 없습니다. 게임은 자기소개 하나로 시작하고, 나머지 증언은 변호인의 질문으로 쌓입니다. 증거가 어떤 증언과 모순되면 증인이 그 증언을 **철회하거나 수정**하고, 한 번 반박된 주장은 거짓말을 하더라도 **다시 말할 수 없습니다**(법정 기록 탭에서 확인). 결정적 증거(정전 기록)로 증언을 반박하면 클리어입니다.

## 진행 방식

1. 증언을 보다가 **질문**합니다(입력창에서 Enter로 제출). 증인은 **한 번에 하나의 사실(한 문장)만** 말하고, 그 답변은 아래에 따로 뜨지 않고 **질문한 증언 바로 뒤에 새 증언으로 삽입**됩니다(1번에서 질문하면 1번과 2번 사이). 한 번 들어온 증언은 취소할 수 없고, 증거로 반박될 때만 철회·수정됩니다. 코드가 답변의 첫 문장만 증언으로 쓰므로 AI가 부연을 붙여도 잘립니다.
2. 증언이 **한도**(`case['statement_limit']`, 사건 01은 20개)에 닿으면 재판관이 "더 이상의 심문은 무의미하다"고 선언하고 **게임 오버**입니다. 반박으로 증언이 철회되면 그만큼 여유가 생깁니다.
3. 증거 탭에서 증거를 고르고 **대사**와 함께 제시합니다. **증언 번호는 입력하지 않습니다.** 증인이 한 말을 짚어서, 이 증거와 왜 모순인지 말하면 됩니다.
   예) `증인은 9시쯤 복도에서 사람을 마주쳤다고 했고 그때 조명이 켜져 있었다고 했는데, 정전 기록은 그 시각 3층이 정전이었다고 합니다.`
   시스템(판정 AI)이 **내용으로** 다음을 차례로 확인하고, 실패한 단계에 맞는 안내를 줍니다.
   - ① 대사가 말한 내용이 현재 증언에 있는가. 모순과 상관없는 곁가지 표현(증인이 쓰지 않은 "피고인" 호칭 등)은 무시되고, 근거에서 제외했다고 알려 줍니다. 증인이 말하지 않은 사실을 지어내 근거로 삼으면 거부됩니다.
   - ② 증거가 대사의 주장을 뒷받침하는가.
   - ③ 가리킨 증언들이 그 증거와 함께 사실일 수 없는가(모순).
   성공하면 증인이 **짚인 증언 중 하나를 철회하거나 수정**합니다. 이때 무너진 증언에 **기대고 있던 다른 증언**이 있으면 증인이 목적에 따라 함께 거두거나 고칩니다(연쇄 반박). 패널티나 신뢰도는 없습니다.
4. **클리어는 재판관 AI가 판단**합니다. 반박이 성공할 때마다 재판관이 사건의 클리어 조건(`case['clear_condition']`)이 법정에서 드러났는지 봅니다. 결정적 증거가 아니어도 핵심 모순에 닿으면 클리어될 수 있고, 반대로 결정적 증거를 써도 핵심에 닿지 않으면 클리어가 아닙니다. AI를 쓸 수 없을 때(키 없음/호출 실패)만 `case['decisive']`의 결정적 증거 규칙으로 되돌아갑니다.

- 증인 AI에게는 법정에 제시된 증거의 이름·설명만 전달하고, 판정 AI의 판정 이유는 전달하지 않습니다(진실이 섞일 수 있어서).
- 증인이 반박된 주장을 되풀이하는지는 판정 AI가 표현이 달라도 같은 주장이면 잡아내고, 걸리면 다시 쓰게 합니다.
- **AI가 하는 판단**: 증인의 답변과 철회/수정, 연쇄로 거둘 증언 고르기, 대사 판정(증언에 있는지·증거가 뒷받침하는지·모순인지), 반복 주장 감지, **클리어 판정**.
- **코드가 하는 일(안전장치)**: AI 응답의 형식 검증(존재하는 증언인지, 마지막 증언은 철회 불가, 길이), 한 문장만 증언으로 저장, 증언 한도와 게임오버, 호출 실패 시 폴백. 승패는 AI 평결을 따릅니다.
- API 키가 없으면 키워드 기반 폴백으로 동작합니다.

## 구조

- `app.py` UI / `flow.py` 질문·선택·증거 흐름 / `engine.py` 증언 상태 / `ai.py` AI 호출 / `cases/case01.py` 사건 데이터
